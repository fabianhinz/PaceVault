# Adopted conventions

Binding on this project. Before changing a file, find the entries whose paths
match it and read those records in `tdr/`. The lines below are pointers, not
the rule — rule text, detection signals and reference implementation live in
the record.

Generated from `tdr/*.md`. Don't hand-edit this file; edit the record.

- `src/**/*.ts` — [Alias imports across directory boundaries](tdr/alias-imports-across-directories.md): A sibling in the same directory is imported relatively; anything outside that directory is imported through the source-root alias, and no specifier ever contains a parent segment.
- `src/**/*.ts` — [An effect only synchronises with something outside React](tdr/effects-are-rare.md): useEffect is reserved for synchronising with a system React does not render; anything computable from props, state or store reads is computed during render instead.
- `src/**/*.ts` — [An index module is a real module, never a re-export barrel](tdr/index-modules-are-not-barrels.md): Nothing in the tree exists purely to forward names from elsewhere — every module declares its own contents and importers address the module that declares the symbol.
- `src/**/*.ts` — [Behavioural constants hoisted to module scope in UPPER_SNAKE_CASE](tdr/behavioural-constants-hoisted-upper-snake.md): A number that governs behaviour is named once at module scope in UPPER_SNAKE_CASE; a one-off structural style value and a design value are both excluded.
- `src/**/*.ts` — [Bind a hook's result whole and read through the name](tdr/hook-results-bound-whole.md): A hook call's return value is bound to one named const and its members read through that name, so a read three screens down still says where the value came from.
- `src/**/*.ts` — [Booleans are named for the state, not with an interrogative prefix](tdr/boolean-names-without-is-prefix.md): A boolean that holds a value is named for the state it describes; only a function or type guard that computes an answer keeps an is/has prefix.
- `src/**/*.ts` — [Deliberate fire-and-forget promises are prefixed with void](tdr/floating-promises-marked-void.md): A promise-returning expression used as a statement is prefixed with the void operator, so a missing await reads as intentional rather than forgotten.
- `src/**/*.ts` — [Design values come from the token layer, never from literals](tdr/design-values-come-from-tokens.md): Every visual quantity is read from a Tailwind theme class or the token module; literal colours, spacings, radii and typefaces are authored in one place only.
- `src/**/*.ts` — [Environment access through a validated facade](tdr/env-access-through-validated-facade.md): Every build-time environment variable is declared in one Zod-validated module and read as a property of its exported env object; nothing reads import.meta.env directly.
- `src/**/*.ts` — [Exhaustive record maps for per-member values, exhaustive switches for per-member behaviour](tdr/exhaustive-record-maps-over-branching.md): A closed union's per-member value is a Record<Union, T> literal indexed directly; its per-member behaviour is a switch with no default arm, so adding a member fails the compiler.
- `src/**/*.ts` — [Native Date with composed millisecond duration constants](tdr/native-date-and-duration-constants.md): Points in time are native Date, durations are milliseconds composed from shared MS_PER_* constants, and no date library is on the dependency graph.
- `src/**/*.ts` — [Navigation and URL state go through the project's own router hooks](tdr/navigation-through-router-hooks.md): Destinations and query keys are registry entries, and feature code navigates and reads URL state through project hooks rather than importing the router.
- `src/**/*.ts` — [One destructured options object once a signature takes more than one input](tdr/signature-parameter-shape.md): A callable needing one thing takes it bare and positional; a callable needing several takes one destructured object holding all of them, typed inline at the declaration.
- `src/**/*.ts` — [One remote call per module, split into fetcher, key and hook](tdr/one-server-call-per-hook-module.md): Each remote call gets one module under src/queries/ or src/mutations/, holding a named async fetcher, an exported key builder, and the hook that wires them together.
- `src/**/*.ts` — [Schemas named with a Schema suffix, types inferred from them](tdr/zod-schema-naming-and-inference.md): Every Zod binding is lowerCamelCase with a Schema suffix, and its compile-time type is inferred from it rather than written out beside it.

- `src/**/*.ts` — [Specs live in a mirrored tests tree](tdr/mirrored-spec-layout.md): Every spec sits under tests/ at the path that mirrors its subject's path under src/, named after the module it covers.
