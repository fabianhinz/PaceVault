# Adopted conventions

Binding on this project. Before changing a file, find the entries whose paths
match it and read those records in `tdr/`. The lines below are pointers, not
the rule — rule text, detection signals and reference implementation live in
the record.

Generated from `tdr/*.md` by `vp run conventions:index`. Don't hand-edit this file; edit the record.

- `apps/web/package.json` — [Native Date with composed millisecond duration constants](tdr/native-date-and-duration-constants.md): Points in time are native Date, durations are milliseconds built from MS_PER_SECOND/MINUTE/HOUR/DAY in packages/engine/src/time.ts, bound to unit-named constants, with no date or duration library.
- `apps/web/src/**` — [A directory's shared vocabulary lives in a colocated types.ts](tdr/colocated-types-module.md): A type, union or constant table read by more than one component or hook module goes in a leaf types.ts beside its readers, never exported from a component or hook for a sibling to import.
- `apps/web/src/**` — [Specs live in one tests tree that mirrors the source tree](tdr/mirrored-spec-layout.md): App specs live under apps/web/tests, mirror their subject's src path, are named <subject>[.<qualifier>].spec.ts(x), never sit under src, and share helpers only through @testUtils.
- `apps/web/src/**` — [Test data comes from createMock factories, never from object literals](tdr/test-data-from-mock-factories.md): Specs build every entity with createMock<Entity>(overrides?) from @pacevault/testing (engine and gpx entities) or apps/web/tests/factories (app entities), passing only the fields the test turns on; series builders live apart in @pacevault/testing/series.ts.
- `apps/web/src/**/*.css` — [Design values come from the theme tokens](tdr/styled-api-over-sx.md): Colours, radii, pixel sizes, type sizes, shadows and kit z-index layers in apps/web, packages/ui, the banner page and the workbench board are read from packages/ui/src/theme.css (or its JS mirror tokens.ts), banner-only px sizes from the banner page's own @theme in tools/docs/banner/page/banner.css; a value the theme lacks first gets a token carrying its exact value, so adopting a token never changes a pixel.
- `apps/web/src/**/*.ts` — [An effect only synchronises with something outside React](tdr/effects-are-rare.md): useEffect is only for external systems (DOM, browser APIs, timers, the map, an external store); derived state is computed during render, I/O goes through read and write modules, react-use hooks replace hand-rolled listeners and timers, and every effect lives in a use<Thing>Effect module named for that system.
- `apps/web/src/**/*.ts` — [An index module is a real module, never a re-export barrel](tdr/index-modules-are-not-barrels.md): Import every symbol from the file that declares it under the @/ alias; no export *, no re-export modules, and an index.tsx only for a directory rendered as a unit.
- `apps/web/src/**/*.ts` — [Bind a hook's result whole and read through the name](tdr/hook-results-bound-whole.md): A hook call's result is bound to one const named for what it returns and read through that name; no destructuring, no renamed members, no stand-in names like query or result.
- `apps/web/src/**/*.ts` — [Booleans are named for the state, not with an interrogative prefix](tdr/boolean-names-without-is-prefix.md): A boolean value is named for the state it holds (open, zoomed, expanded), persisted fields keep their names; only a function or type guard that computes a boolean takes the is/has prefix.
- `apps/web/src/**/*.ts` — [Component props are derived from the component value](tdr/library-type-narrowing.md): A component that wraps or delegates to another derives that prop surface with ComponentProps<typeof X> (composing Pick/Partial/Required over it), never restates it; children-only components are FC<PropsWithChildren>.
- `apps/web/src/**/*.ts` — [Deliberate fire-and-forget promises are prefixed with void](tdr/floating-promises-marked-void.md): A promise deliberately not awaited is marked with the void operator (async callbacks are wrapped as () => void fn()), and a call whose rejection matters is awaited instead.
- `apps/web/src/**/*.ts` — [Design values come from the theme tokens](tdr/styled-api-over-sx.md): Colours, radii, pixel sizes, type sizes, shadows and kit z-index layers in apps/web, packages/ui, the banner page and the workbench board are read from packages/ui/src/theme.css (or its JS mirror tokens.ts), banner-only px sizes from the banner page's own @theme in tools/docs/banner/page/banner.css; a value the theme lacks first gets a token carrying its exact value, so adopting a token never changes a pixel.
- `apps/web/src/**/*.ts` — [Error subclasses declared at the throw site, caught by type at the boundary](tdr/domain-error-subclasses.md): A failure a consumer branches on gets an Error subclass named for the condition, declared in the module that throws it, carrying its data as readonly fields and caught with instanceof at the deciding boundary; everything else throws a bare Error.
- `apps/web/src/**/*.ts` — [Every context ships with its accessor hook in one provider module](tdr/context-provider-accessor-pairs.md): A project-declared React context, its use<Name>Context accessor and its provider live in one <Name>Provider.tsx; nothing else calls useContext on it, the context defaults to undefined, use<Name>Context throws outside the provider, and callers that may render outside it read useUnstable<Name>Context.
- `apps/web/src/**/*.ts` — [Exhaustive record maps for per-member values, exhaustive switches for per-member behaviour](tdr/exhaustive-record-maps-over-branching.md): A closed union's per-member value is a Record<Union, T> named VALUE_BY_KEY and indexed without fallback; per-member behaviour is a switch with no default; unions with a runtime list derive from it.
- `apps/web/src/**/*.ts` — [Helpers with generic names are exposed as one namespace object](tdr/helpers-as-namespace-objects.md): A helper module whose functions have short or generic names exports one plain object named after the file, built from shorthand references to module-local functions; self-describing helpers stay loose exports.
- `apps/web/src/**/*.ts` — [Native Date with composed millisecond duration constants](tdr/native-date-and-duration-constants.md): Points in time are native Date, durations are milliseconds built from MS_PER_SECOND/MINUTE/HOUR/DAY in packages/engine/src/time.ts, bound to unit-named constants, with no date or duration library.
- `apps/web/src/**/*.ts` — [Navigation and URL state go through the project's own router hooks](tdr/navigation-through-router-hooks.md): Every destination is a named page in src/routing/pageRegistry.ts reached through usePageRouting, URL state goes through useRouterParam/useRouterQuery, react-router-dom is imported only in src/routing/, and in-app links are PageLink, never the framework's Link/NavLink.
- `apps/web/src/**/*.ts` — [One destructured options object once a signature takes more than one input](tdr/signature-parameter-shape.md): A function, method or hook taking two or more inputs declares one destructured object parameter typed inline; one input stays bare; generic utilities, trailing infrastructure handles and library-imposed signatures are the only positional exceptions.
- `apps/web/src/**/*.ts` — [One hook per module, module named after the hook](tdr/one-hook-per-file.md): A module exports at most one hook, never sits inside a component module, and a use*-named module's basename equals its exported hook's name.
- `apps/web/src/**/*.ts` — [Schemas named with a Schema suffix, types inferred from them](tdr/zod-schema-naming-and-inference.md): Every zod binding is lowerCamelCase with a Schema suffix, and its TypeScript type is z.infer of it, named as the schema name in PascalCase minus the suffix.
- `apps/web/src/**/*.ts` — [Store state: initial state as a value, narrow selections, draft writes](tdr/single-zustand-store-of-slices.md): A store whose initial state is restated by a test reset or a reset action exports it as INITIAL_<NAME>_STORE_STATE; components select the narrowest value (useShallow for built objects, never the whole store); writes mutate the Immer draft, never return a spread copy.
- `apps/web/src/**/*.ts` — [Transient feedback declared in feature-scoped snackbar maps](tdr/snackbar-feedback-via-feature-maps.md): Toast feedback is declared once as an entry in a <feature>Snackbars.ts map closed with satisfies SnackbarMap, keyed <MAP>_<entry>, and raised with useSnackbar().enqueueSnackbar(entry); feature code never writes to the toast store.
- `apps/web/src/**/*.ts` — [Units grow wide, not deep](tdr/unit-length-discipline.md): A function, hook or component holds at most about a dozen statements and nests at most three deep (components one, two at most); extracted statements become hooks or topic-module steps, extracted markup its own component module, and line count is never the trigger.
