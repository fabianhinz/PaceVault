Studio marker dialog: button layout on phone

Delete is a trash icon button on the left with a wider gap to Cancel · Save, and Save stays disabled while the km field is empty. Fast lane: Changes, Verification, How to check.

Changes

C1Delete as an icon, wider gap to Cancel · Save

In edit mode Delete is a danger icon button (trash, accessible name "Delete") at every width. On phone it sits left with 16 px to Cancel, against 8 px between Cancel and Save; on desktop it stays far left (Q1, Q2). The footer rule in apps/web/CLAUDE.md:45 now allows it in a three-action footer.

C2Empty km field disables Save

Save needs the km field to hold a number, so clearing it no longer saves the marker at 0 km (Q3). An entered 0 still saves.

How to check

  1. At 390 px, EN and DE: open a route in the studio, Tools tab, edit a waypoint. The trash icon sits left, Cancel · Save right, with a wider gap after the icon.
  2. Clear the km field: Save turns disabled; type a number again and it turns enabled.
  3. On desktop: the trash icon sits far left, Cancel · Save on the right.
