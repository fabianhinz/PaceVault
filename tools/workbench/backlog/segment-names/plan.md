# Name segments

## Idea

Detected segments only carry type + number labels (`Climb 1`, `Flat 2`, `Route 1`, session-segments Q10), which are hard to tell apart and can shift when re-detection renumbers them. Let the user give a segment their own name that survives re-detection. Spun off from `session-segments` (Q1 c, fixed user segments).
